# 汇川电液伺服产品选型指南 (机械设计工程师版)

本指南旨在帮助机械设计工程师快速理解汇川电液伺服产品在不同应用场景下的选型逻辑，并提供典型的配置方案与注意事项。

## 一、 学习路径概览

1.  **理解核心原理**：首先需要明确电液伺服系统的基本组成（驱动器 + 电机 + 控制器/泵站）及其在节能、精度、响应速度方面的优势。
2.  **熟悉产品系列**：对照手册，了解各系列驱动器的定位与核心特点：
    - **ES510系列**：标准型，性价比高，适用于大多数通用油压场景。
    - **IS580系列**：标准型油压伺服，性能稳定。
    - **ES590系列**：高可靠、油冷设计，适合环境恶劣或对散热要求高的场合。
    - **ES650N系列**：总线型，支持高速实时EtherCAT通讯，适合多轴协同或高精度控制。
    - **ES580C系列**：工程型一体机，集成度高，简化系统布线。
    - **ES630P系列**：通用型伺服，灵活性高。
    - **ES810系列**：全电多机传动，适用于完全取消液压系统的全电动方案。
3.  **匹配应用场景**：根据目标机械（注塑机、压铸机等）的工艺要求、负载特性、控制精度和成本预算，选择最合适的驱动器系列与电机组合。
4.  **确定配置方案**：根据系统要求的**流量**和**压力**，计算出所需电机的**功率**和**转速**，进而匹配驱动器的**额定电流**。

## 二、 按场景的典型配置方案

### 1. 注塑机

- **场景特点**：要求流量大、压力高、响应快，且对节能效果有显著要求。通常采用“伺服驱动器 + 永磁同步电机 + 内啮合齿轮泵/柱塞泵”的节能方案。
- **典型配置方案**：
    - **驱动器**：`ES510` 系列 或 `IS580` 系列 (标准性价比方案)
    - **电机**：汇川配套的油压伺服永磁同步电机
    - **控制器**：注塑机专用控制器 (通常由主机厂提供，通过CANopen或模拟量控制)
- **选型注意事项**：
    - **流量与转速匹配**：根据注塑机各动作（射胶、熔胶、开合模）所需的最高流量，计算电机最高转速。
    - **压力与转矩匹配**：根据系统最高工作压力，计算电机峰值转矩。
    - **惯量匹配**：对于快速响应的射胶动作，需关注电机与泵的惯量比。
    - **关注点**：重点考虑`ES510`的免调谐功能和内置油压控制算法，可大幅缩短调试时间。

### 2. 压铸机

- **场景特点**：冲击大、震动强、对系统可靠性要求极高，尤其在合模和压射环节需要极高的爆发力和响应速度。
- **典型配置方案**：
    - **驱动器**：`ES590` 系列 (高可靠油冷方案) 或 `IS580` 系列
    - **电机**：高过载能力的油压伺服电机
    - **控制器**：压铸机专用控制器
- **选型注意事项**：
    - **过载能力**：压铸机在压射瞬间电流冲击极大，必须确认驱动器和电机的短时过载倍数（通常需达到2-3倍额定电流）。
    - **散热环境**：压铸车间通常高温、多粉尘。`ES590`的油冷设计能有效隔离恶劣环境，保证散热效果。
    - **抗振性**：确保驱动器和电机的安装结构能承受压铸机工作时的强烈震动。
    - **硬件选型**：优先考虑`ES590`系列，其高可靠设计更适合此工况。

### 3. 油压机

- **场景特点**：工艺多样（拉伸、冲压、校正），对压力和位置的控制精度要求高，保压性能是关键。
- **典型配置方案**：
    - **驱动器**：`IS580` 或 `ES630P` 系列 (通用灵活方案)
    - **电机**：标准油压伺服电机
    - **控制器**：PLC 或 专用运动控制器 (通过Profinet/EtherCAT通讯)
- **选型注意事项**：
    - **保压性能**：评估驱动器的闭环控制算法，确保在保压阶段电机能稳定输出转矩，压力波动小。
    - **位置控制精度**：若需要精确控制滑块位置，应选择支持高精度编码器（如`ES630P`或`ES650N`）的驱动器，并配合磁栅尺或光栅尺。
    - **多缸同步**：对于大型油压机，可能需要多缸同步控制。此时应选择`ES650N`等支持高速总线（EtherCAT）的驱动器，以实现多轴精确同步。
    - **通讯协议**：明确上位机控制器支持的通讯协议（CANopen, Modbus, Profinet），确保驱动器兼容。

### 4. 折弯机

- **场景特点**：对滑块同步性（Y1/Y2轴）要求极高，需要极高的位置控制精度和重复定位精度。
- **典型配置方案**：
    - **驱动器**：`ES650N` 系列 (总线型高精方案) 或 `IS580` 系列
    - **电机**：高精度油压伺服电机
    - **控制器**：折弯机专用数控系统 (通过EtherCAT总线控制)
- **选型注意事项**：
    - **同步控制**：这是折弯机最核心的需求。必须使用支持EtherCAT总线的高性能驱动器（如`ES650N`），实现纳秒级的同步抖动。
    - **编码器类型**：建议配套使用高分辨率绝对值编码器，以实现断电记忆位置，无需每次开机回零。
    - **全电方案探索**：对于小吨位折弯机，可以考虑`ES810`系列全电伺服方案，直接驱动丝杆，彻底消除液压系统的非线性影响，达到更高精度。

## 三、 通用选型注意事项

1.  **电源与电网**：
    - 确认驱动器输入电压等级 (手册中为 **380\~480V AC**)，并考虑电网波动。
    - 大功率系统需考虑配备**输入电抗器**和**直流电抗器**，以抑制谐波和改善功率因数。

2.  **编码器匹配**：
    - 根据电机类型和精度要求选择编码器。手册中`ES510`系列适配**旋转变压器**和**A3系列高性能编码器**。
    - 旋转变压器：耐用、抗振，适用于环境恶劣场合。
    - 增量式/绝对值编码器：精度更高，适用于高精度控制。

3.  **散热与安装**：
    - 计算驱动器与电机的发热量，确保控制柜有足够的通风或配备空调。`ES590`的油冷方案是解决高温环境散热问题的利器。
    - 安装时需预留足够的散热空间，参照手册中的**安装孔位**和**外形尺寸**。

4.  **通讯网络**：
    - 规划好控制网络拓扑。手册中汇川产品支持**CANopen**、**Modbus**、**Profinet**、**EtherCAT**等多种协议。
    - 对于需要高速、实时、多轴协同的场景，**EtherCAT**是首选。

5.  **命名规则解读**：
    - 以 `ES510T037-XX` 为例：`ES510`系列，`T`表示三相380V，`037`表示额定输出电流37A。这是选型时匹配电机功率的关键参数。

6.  **辅件与安全**：
    - 务必配置**制动电阻**，特别是在电机快速减速或负载倒拖（如压铸机开模、折弯机回程）的场合。
    - 设计安全回路，确保在急停或故障时能可靠切断电机动力。
